## Startup and isolation

`RADAR_FRONTDOOR_ONLY=true` returns before normal pool/store construction and RH automation setup, as documented and tested in the existing frontdoor candidate review. In that mode RH routes are denied by default. Enabling `/v1/rh-chain/*` wholesale would bypass the intended isolation boundary and would reach handlers whose route constructors assume normal store wiring. The current curated allowlist in `src/api/curatedReadRoutes.ts` contains no RH route.
