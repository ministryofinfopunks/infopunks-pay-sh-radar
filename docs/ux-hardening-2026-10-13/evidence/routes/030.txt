    - region "Integration code example":
      - code: "import { createInfopunksClient, createX402WalletPayment } from \"infopunks-pay-sh-radar/sdk\"; const client = createInfopunksClient({ baseUrl: \"https://radar.infopunks.fun\", apiKey: process.env.INFOPUNKS_TENANT_KEY!, payment: createX402WalletPayment({ signer: walletSigner, policy: { network: \"eip155:8453\", asset: \"USDC\", payTo: operatorPayTo, maxAmountAtomic: \"25000000\" }, approve: async ({ judgment }) => confirm(`Pay ${judgment.cost.amount} ${judgment.cost.asset} for this Judgment?`) }) }); const result = await client.judge({ intent: \"buy_market_research\", subject: \"service:market_research\", budget: 25, risk: \"low\", requiredConfidence: 80 }); // Returns only after the canonical receipt is verified. This never executes the spend. console.log(result.state, result.canonical_judgment);"
  - region "POST /v1/pre-spend/check":
    - paragraph: API
    - heading "POST /v1/pre-spend/check" [level=2]
    - paragraph: "Canonical decisions: proceed, test_spend_first, do_not_spend, insufficient_evidence. Inspect canonical_judgment; legacy diagnostic verdicts cannot authorize spend. Subject network is independent of fee settlement. The strict radar-judgment-context.v1 extension binds a namespaced subject, policy version, accepted evidence references, fee settlement network and expiry. RH market policy remains read-only and unqualified for trading. Native Solana fee settlement is unavailable. Canonical proof reads require operator authentication."
    - paragraph: Builders can call the HTTP endpoint directly when they do not want the SDK wrapper. The public contract is the intelligence layer before payment, not the payment client itself.
