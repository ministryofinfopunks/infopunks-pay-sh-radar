# Distinct immutable evidence baselines

PR #16 is frozen at `d6b77e573f9939d4af70bdbd9416619001bf3cf9`; PR #17 at `d859c5dc13948f312c3652539704cea06d903cd3`. They are separate evidence universes. R3 is a child of #17 solely for an isolated tools-only draft. It does not merge #16's later two-stage experiment or change either PR, history or qualification claim.

Each `pr-N.manifest.json` records the exact commit/tree/parents, complete per-file Git blob IDs and raw byte SHA-256 values, original PR metadata snapshot and separately attributed claims. The capture timestamp is not a test execution date or independent approval. Manifests include aggregate file-map digests with sorted canonical JSON. Generated locally from exact Git objects; historical CI links in original descriptions remain historical claims, not fresh R3 CI evidence.

`source-manifest.mjs` verifies the complete baseline inventories against those Git objects and records candidate head/tree, package byte hashes, baseline references and source preservation. It requires a clean committed checkout and rejects changes outside `tools/first-spender-trust-r3/` and the exact new offline workflow `.github/workflows/first-spender-trust-r3.yml` relative to #17. Every historical file in that base remains byte-identical, including #17's heldout, preregistration, reports, production source and workflows. It never invokes the older R2 source verifier at the R3 head, which would correctly reject this R3 directory outside its R2 allowlist. The package also avoids broad legacy `tools/spend-lab/**` CI triggers, so new checks do not silently repurpose baseline qualifications.

The manifest preserves the PR metadata observed at capture and re-verifies object content; it does not prevent remote branch movement. Re-read PR heads for submission/review and report any drift. Do not force push, edit either PR's claims or point a baseline branch at R3. Independent approvals apply to exact candidate source and actual evidence scope, not merely the PR number.
